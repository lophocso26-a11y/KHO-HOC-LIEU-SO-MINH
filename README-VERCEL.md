# FUN SPORTS DAY — Vercel edition

## Deployment

1. Extract this ZIP, upload its contents to a **private GitHub repository** (not the ZIP file itself).
2. In Vercel, **Add New → Project → Import Git Repository**.
3. Framework: **Vite**; Build Command: `npm run build`; Output Directory: `dist`.
4. In **Settings → Environment Variables**, add `GEMINI_API_KEY` with your Gemini API key (server-side only). Redeploy after adding it.
5. Visit your URL and test the welcome narration, six activity speakers, quizzes and test phrases.

## How audio works

- All 25 pre-generated WAV clips are preserved in `public/audio_cache` and served as static files.
- The Vercel serverless function `api/tts.ts` returns a cached clip URL when the requested phrase is present.
- Other phrases are generated by Gemini TTS using the same model/voice/style logic from `server.ts`, and returned as a data URI because serverless disk writes are not persistent.
- If API quota/key is missing or synthesis fails, the existing browser speech fallback remains; its voice quality may differ.
- Each new synthesis consumes Gemini API quota; data URIs are cached only in the browser session.
- Gemini model availability and audio format must be validated with a live API key. Existing server implementation treats returned PCM as WAV; this package preserves that behavior, so dynamically generated speech may require an additional PCM-to-WAV fix if the provider returns raw PCM.

## Important

Never put API keys into source code, public files or GitHub. `server.ts` is retained for AI Studio/local usage, but Vercel uses `api/tts.ts` instead.
